# Ink

> Ink is a private memory for your writing.

Ink is a private writing workspace that remembers everything you write, and helps you rediscover forgotten pieces, connect fragments, and notice patterns across your work over time.

This repository is open source under the MIT licence (see [LICENSE.md](./LICENSE.md)). It is not currently open to external contributions (see [CONTRIBUTING.md](./CONTRIBUTING.md)).
